# PDF to Audio Converter with Python

## Overview

This project extracts text from PDF documents and converts it into spoken audio using Python. It combines PDF text extraction, text-to-speech conversion, and Twilio API integration to explore automated audio generation and voice-response workflows.

## Technologies Used

- Python
- PyPDF2 — PDF text extraction
- gTTS — Text-to-speech conversion
- Twilio Python SDK — Voice API and TwiML generation
- python-dotenv — Environment variable management
